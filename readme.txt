# DSPatcher

DSPatcher is a camera tuning patcher designed for Direct Sensor Photography.

It helps correct lens shading and uneven color distribution caused by replacing the original camera lens cover with external lenses.

## Features

- Supports Qualcomm and MediaTek camera tuning files.
- Supports BIN and SO file formats.
- Extracts LSC data from DNG flatfield images.
- Applies flatfield-based Lens Shading Correction (LSC).
- Unified LSC processing through a dedicated adapter.
- Generates patched camera tuning files.
- Creates flashable Magisk modules.

## How to Use

1. Upload your original camera tuning file (.bin or .so).
2. Upload a DNG flatfield image captured with your Direct Sensor setup.
3. Apply the LSC correction.
4. Download the patched camera tuning file or Magisk module.

## Disclaimer

Always back up your original camera tuning files before applying modifications.

DSPatcher is provided for experimental and research purposes. Use it at your own risk.
